## [0.2.0] - 2026-10-31

### Added

- Brand: geometric lantern logo, lockups, mono and light variants and an adaptive favicon
  (`assets/`, generated by `tools/build_logo.py`).
- Provider-agnostic core: xAI, Google Gemini (free tier) and Groq (free tier) through
  OpenAI-compatible clients, chosen with `--provider` / `FANOOS_PROVIDER` or the first key present.
  On providers without live search the persona is kept verbatim, an instruction is appended, and
  reports end with «بدون جستجوی زنده».
- `fanoos providers` command.
- FastAPI server (`uvicorn server:app`): web UI, `POST /api/review` (JSON URL or PDF upload),
  `GET /health`, `GET /api/providers`.
- Web UI: Persian RTL / English LTR landing page built around a procedural Three.js lantern that
  reacts to the review (thinking, done), follows pointer and scroll, pauses off-screen, adapts to
  weak GPUs, respects reduced motion and falls back without WebGL. Built-in sample report.
- n8n workflows (webhook and optional Telegram bot) and `docs/n8n.md`.
- `Review` now carries `provider`, `model` and `live_search`.

### Changed

- Error messages are bilingual (English and Persian) and name the provider; 429s are retried with
  backoff before failing.
- Default models: `gemini-flash-latest` and `openai/gpt-oss-120b`, because `gemini-2.0-flash` and
  `llama-3.3-70b-versatile` have been retired by their providers.

### Security

- The server refuses private, loopback and link-local URLs and limits uploads to 15 MB PDFs.
- Model output is rendered as text only in the web UI.

## [0.1.0] - 2026-10-31

### Added

- `Fanoos` agent that streams reviews from the xAI Responses API (`https://api.x.ai/v1`) with
  the `web_search` and `x_search` Agent Tools enabled on every request.
- The validated Fanoos persona embedded verbatim in `fanoos/system_prompt.py`.
- `Review` dataclass and a parser that reads the model's JSON summary and falls back to its
  Markdown sections.
- Portfolio input from a URL (page text pre-fetched) or a local PDF.
- `fanoos review` CLI: streamed bilingual report with right-aligned Persian, scorecard, `--json`,
  `--raw`, `--no-stream`, `--lang`, `--focus`, `--model`, `--no-fetch` and `--bidi`.
- Clear error messages and exit codes for a missing or rejected API key, network failures,
  rate limits (429), other API errors, malformed output and unreadable input.
- Offline pytest suite and GitHub Actions CI on Linux, macOS and Windows with Python 3.10 and 3.12.
