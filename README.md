# Negar Zahed

**UI/UX Designer · Web Designer · Frontend Developer**

I design clear interfaces and interactive web experiences, then build them myself. My work runs from information architecture and interface design to responsive front-end implementation, so nothing gets lost between the design file and the browser.

## What I do

- **UI/UX design:** user journeys, information architecture, wireframes and high-fidelity interfaces
- **Web design:** visual hierarchy, layout and personal branding for the web
- **Interaction design:** motion, states and feedback that carry meaning rather than decoration
- **Responsive front-end development:** layouts that hold from wide desktop down to a 390 px phone
- **Persian (RTL) and bilingual interfaces:** Persian treated as a first-class experience, not a translation
- **Design systems:** shared tokens, components and rules that keep a product consistent

## Selected work

### [Venture Compass](https://negarportfolio.ir/venture-compass/)
*Ongoing.* A Persian-language platform that connects startups with investors, expertise, education and community, so founders always know which way the next step is.
My work: information architecture, user journeys, interactive navigation, visual and motion direction, and the design system, plus a responsive front-end with a Persian RTL interface.
The production build is in progress (Next.js · TypeScript · Payload CMS · PostgreSQL, private repository).

### [Amirali Majidi: personal brand website](https://amiralimajidi.ir/)
*Completed · Live.* A personal brand and portfolio website for a business development strategist. It turns career history, education, work, articles and projects into one clear, navigable story.
My work: information architecture, visual hierarchy, personal branding, interaction design, content structure, and a responsive front-end from wide desktop to 390 px mobile.

### [O2Life: quit-smoking companion](https://github.com/zahednegar-hub/o2life)
*UI/UX concept · front-end prototype.* A Persian web app concept for people quitting smoking. It covers a landing page, sign-up, a nine-step onboarding questionnaire and a progress dashboard, with motion that tells the story (a cigarette that burns down as you scroll).
Built with HTML, CSS and vanilla JavaScript, plus Chart.js. · [Live demo](https://zahednegar-hub.github.io/o2life/) · [Code](https://github.com/zahednegar-hub/o2life)

### [Pink Venom AI Hub](https://negarportfolio.ir/pink-venom/)
*Product concept.* A concept hub for AI tools (agents, chat, model settings, automation and billing), built around a deliberate pink-and-black identity.

## AI-assisted workflow

I use AI tools the way designers use any tool: to research faster, explore more directions and ship cleaner front-end code. The design decisions stay mine.

1. **Research and discovery:** mapping a domain, its competitors and its user questions before the structure is decided
2. **Design and prototyping:** exploring more layout and interaction directions early, then refining one by hand
3. **Front-end development:** building, debugging and reviewing code faster, with every line checked and understood
